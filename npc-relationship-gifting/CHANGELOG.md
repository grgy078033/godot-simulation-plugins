# Changelog

## 1.0.1 — Open-source release

- Released under MIT; free downloads with optional donations.
- Added the shared source repository, issue tracker and optional Star link.
- Runtime scripts, demo scenes and Resources are unchanged from 1.0.0.

## 1.0.0 — 2026-02-17

- Added typed `RelationshipProfile`, `GiftPreference` and `RelationshipLevel` Resources.
- Added clamped `RelationshipComponent` point state, level resolution and gift application.
- Added `GiftResult`, relationship/gift signals and deterministic null/duplicate edge handling.
- Added editable Alice profile resource and native external-controls demo.
- Added focused headless core and native demo validation scripts.
