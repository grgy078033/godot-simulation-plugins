# Changelog

## 1.0.1 — Open-source release

- Released under MIT; free downloads with optional donations.
- Added the shared source repository, issue tracker and optional Star link.
- Runtime scripts, demo scenes and Resources are unchanged from 1.0.0.

## 1.0.0 — 2026-02-17

- Added typed `ScheduledEvent` and `EventSchedule` Resources for daily, overnight and concurrent event windows.
- Added `WorldEventScheduler` Node with destination-state reconciliation and start/end signals.
- Added deterministic validation for empty/invalid entries, duplicate IDs, zero-duration windows and normalized query clocks.
- Added editable example schedule and native external-clock demo.
- Added focused headless core and native demo validation scripts.
