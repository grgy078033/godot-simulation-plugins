# Changelog

## 1.0.1 — Open-source release

- Released under MIT; free downloads with optional donations.
- Added the shared source repository, issue tracker and optional Star link.
- Runtime scripts, demo scenes and Resources are unchanged from 1.0.0.

## 1.0.0

- Normalized release numbering for the Godot Simulation Systems collection.
- Added related-product documentation; scheduler runtime behavior is unchanged.
- The original v1.0 archive and its validation record are retained locally.

## 1.0

- Added Inspector-friendly `ScheduleEntry` and `NPCSchedule` Resources.
- Added current/next routine queries and minutes-until-next calculation.
- Added overnight wrap, unsorted entry support and safe empty handling.
- Added `NPCScheduler` with identity-based schedule change signals.
- Defined deterministic duplicate-time, invalid-slot and single-entry behavior.
- Included a three-NPC demo with forward/backward hourly controls.
- Included integration examples and commercial asset license.
- Validated on Godot 4.7.2 stable (Windows, Compatibility renderer).
