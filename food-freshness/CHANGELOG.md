# Changelog

## 1.0.1 — Open-source release

- Released under MIT; free downloads with optional donations.
- Added the shared source repository, issue tracker and optional Star link.
- Runtime scripts, demo scenes and Resources are unchanged from 1.0.0.

## 1.0.0 — 2026-02-17

- Added typed `FreshnessProfile` Resource with normalized fresh and stale day durations.
- Added per-item `FreshnessInstance` RefCounted with pure state, age and countdown queries.
- Added explicit freshness transition and expiration signals with rewind-safe updates.
- Added editable freshness profile and native external-day demo for Milk, Fish and Bread.
- Added focused headless core and native demo validation scripts.
